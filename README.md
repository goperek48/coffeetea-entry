Entry for make.fun's **One Letter: Coffee or Tea** bounty
(`u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`).

`main.py` writes exactly one letter to `/output/entry.txt`:

> A

A for coffee — the bolder, more vivid answer in the coffee-against-tea
argument: dark, hot, loud, the drink that wakes you up and starts the
day. One letter, the whole argument, nothing needed beside it.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (validated: exactly one letter, A or B, UTF-8).
